# Roadmap

Larger planned features and product direction.

## Client Brief Automation

- Generate draft homepage content from Client Brief data.
- Generate Services CPT entries from Client Brief service notes.
- Generate FAQ CPT entries from Client Brief FAQ ideas.
- Generate HowTo CPT entries from Client Brief guide topics.
- Generate LocalBusiness, Service, FAQ, and HowTo content recommendations from stored client context.
- Export a full project package containing `sbo_options`, `sbo_client_brief`, and relevant CPT content.

## Client Brief Workflow

- Add preview mode before filling live site fields from Client Brief.
- Add explicit overwrite mode for mapped site fields with confirmation.
- Add Markdown export/import for full project data beyond Client Brief.
- Add option to create or update `CLIENT.md` from the WordPress Client Brief.
- Add option to import `CLIENT.md` directly into WordPress.

## Admin UX

- Improve Client Brief navigation for long forms, such as section tabs, jump links, or collapsible groups.
- Add completion indicators for Client Brief sections.
- Add field-level status showing whether each Client Brief field is used by site settings, service generation, FAQ generation, or content planning.
- Add copy-to-clipboard buttons for AI-ready client context summaries.

## Data Management

- Fix and modernize CSV import/export for the current business field schema.
- Add JSON export/import for structured backups.
- Add migration helpers if Client Brief schema keys change.
- Add validation summaries for missing core business data, NAP fields, CTAs, and SEO basics.

## Content / SEO

- Add service page templates informed by Client Brief values.
- Add location/service area page planning tools.
- Add FAQ suggestions based on services, objections, and customer triggers.
- Add review/testimonial organization tools for proof sections.
